# Plumix — документы оркестрации

Карта продуктовых и маркетинговых документов проекта. Код живёт в дочерних
репозиториях (`Plumix`, `Plumix.Packages`, `NetBench`, `landing`; `.github` —
только профиль организации), их собственные инструкции — в `AGENTS.md`
каждого репо; общий гид по мультирепо-работе — `../agents.md`.

Инженерные трекеры фреймворка (roadmap, порт Cupertino, матрицы паритета)
остаются в коде: `Plumix/docs/FRAMEWORK_PLAN.md`, `Plumix/docs/CUPERTINO_TODO.md`,
`Plumix/docs/ai/`. История изменений — `CHANGELOG.md` каждого репо.

Перенесены из `Plumix/meta/` и `NetBench/IDEA.md` 2026-10-24. Обновлять
таблицу при смене статуса документа.

## product/ — что строим

| Документ | Что это | Статус |
|---|---|---|
| `netbench.md` | Концепция демо-приложения NetBench: гибрид desktop (Avalonia) + mobile (Plumix), перф-приёмы движка, функциональность, экраны, демо-сценарии для показа, фазы разработки, что оно показывает о Plumix | перенесён 2026-10-24 без правок; чекбоксы фаз не сверены с кодом (движок, desktop и mobile UI уже есть в `NetBench`, синхронизации через Supabase нет) |

| `avalonia-free-api.md` | PRD: публичный API `Plumix`, `Plumix.Material`, `Plumix.Cupertino` без типов Avalonia до заморозки `1.0` — шесть принятых решений (геометрия структурами, `Dx`/`Dy`, хост в пакете `Plumix.Avalonia`, равенство с NaN, шрифты через `FontLoader`, закрытые внешние текстуры), инвентарь утечки, этапы, критерии готовности, риски | создан 2026-11-20; реализован 2026-11-21 и выпущен в `1.0.0-preview.5`, итоги и отступления — в конце документа |
| `avalonia-free-core.md` | PRD: сборка `Plumix` без ссылок на Avalonia и SkiaSharp (картинка `Canvas` как данные, внутренние интерфейсы бэкенда, реализация на Avalonia и Skia в `Plumix.Avalonia`) и прототип нативного хоста Android на NImpeller — инвентарь внутренних зависимостей, возможности и пробелы C API Impeller, этапы, критерии, риски | создан 2026-11-21; восемь решений приняты, четыре вопроса открыты (имена пакетов, чтение пикселей, формат шейдеров, прототип на iOS); 2026-11-21 — этапы 0–3 выполнены (ветка `rc/avalonia-free-core` в `Plumix`): `Picture`, `Path`, `Shader` и фильтры — данные, поток UI, картинки, растеризация и текст — в хосте, `Plumix.csproj` без пакетов Avalonia/SkiaSharp/HarfBuzzSharp; 2026-11-22 — прототип на NImpeller (ветка `proto/impeller`) проверен на Pixel 4a 5G: APK 25,7 против 36,2 МБ, тёплый старт 638 против 1086 мс, прокрутка без пропусков кадров, экраны NetBench работают, список пробелов C API составлен; дальше решение (этап 5) |
