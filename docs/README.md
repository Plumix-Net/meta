# Plumix — документы оркестрации

Карта продуктовых и маркетинговых документов проекта. Код живёт в дочерних
репозиториях (`Plumix`, `Plumix.Packages`, `NetBench`, `landing`; `.github` —
только профиль организации), их собственные инструкции — в `AGENTS.md`
каждого репо; общий гид по мультирепо-работе — `../agents.md`.

Инженерные трекеры фреймворка (roadmap, порт Cupertino, матрицы паритета)
остаются в коде: `Plumix/docs/FRAMEWORK_PLAN.md`, `Plumix/docs/CUPERTINO_TODO.md`,
`Plumix/docs/ai/`. История изменений — `CHANGELOG.md` каждого репо.

Перенесены из `Plumix/meta/` и `NetBench/IDEA.md` 2026-10-24. Обновлять
таблицу при смене статуса документа.
